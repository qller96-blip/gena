# GENA

Конструктор промтов для продуктовых сцен КуулКлевер (Nano Banana, GPT Image).

Один статический файл `index.html` (для всех). `v2.html` перенаправляет на `index.html`; прежняя версия удалена (её можно достать из истории git). Вход, шаблоны команды и аналитика работают через Supabase (проект `gena`, eu-central-1).

## Как устроено

| Что | Где |
|---|---|
| Вход | Supabase Auth. Любая почта + общий пароль команды. Проверка пароля — в триггере базы (`gena_before_signup`), сам пароль лежит в закрытой схеме `private` |
| Шаблоны команды | Таблица `templates`. Видны всем вошедшим, имя автора берётся из профиля |
| Тестовые шаблоны и концепты (только админ) | Та же таблица `templates`, флаг `test = true`: такие строки видит только админ (RLS). В конструкторе — вкладка «Тестовые», в «Идеях» — раздел «Концепты»: название, задача, продукт, заметка и картинки (`images`: результаты и референсы, файлы в `works/<uid>/concepts/<id>/`). «В команду» снимает флаг |
| Аналитика | Таблица `scene_events`, читает только админ. Копирование (`copy`: источник `via` — конструктор/идеи/макет, `edits` — нажатий до промта, `t` — мс от входа, `first`), вход `open` и вкладки `view`, `idea` (открыли сцену), `rate`, `publish`, `like`, `undo`, `help`, `copyfail`; у всех `sid` сессии и `mob`. Дашборды — меню профиля → «Аналитика и доступ»: Обзор, Удобство, Качество, Люди, Сцены, Отзывы, Доступ; период 7/30/90/всё и «Без моих действий» |
| Витрина «Идеи» (режим Простой) | Таблица `showcase`: название карточки, задача, продукт, подборка, скрытие. Строится поверх `publications`, читают все, пишет только админ (окно идеи → «Витрина»). «Идеи» — главный экран для всех: одна бенто-сетка, фильтры по типу баннера и продукту
| Макет сцены (вкладка «Макет», для всех) | Продукты, декор, текст и подставка расставляются на холсте; промт (текст или JSON) собирается с координатами. Главная кнопка «Промт и набросок» копирует промт и скачивает PNG-набросок (сцена в её цветах, со вшитыми шрифтами), который прикладывается последним. Подписи превращают фигуры в конкретные предметы, «Декор от нейросети» добавляет тематический декор. Режим ПП: баннер 1100×600 внутри кадра генерации (16:9, GPT 2208×1216, 3:2). Макеты сохраняются в `prompt_history` с `state.mode = "scene"` и публикуются в галерею парой «макет + картинка». Сцена в браузере — `gena-scene-v1`, шрифты — IndexedDB `gena-fonts` |
| Интерьер (Макет и Конструктор) | Один словарь в `index.html` (блок «ИНТЕРЬЕР»): `ROOMS` (15 помещений), `RSTYLE`, `RTONE` (тон отделки), `RTIME` (утро…ночь). Промт описывает столешницу и помещение одним пространством (`persEn`: одна камера, горизонт, точка схода) и ансамблем (`harmEn`); «Подбирать к интерьеру» берёт столешницу из `envPicks`. «На весь фон» — материал поверхности до верха кадра (`fullEn`). В Макете настройки — во вкладках «Сцена · Продукты · Декор · Текст» |
| Несколько картинок в публикации | `publications.cap` — подпись обложки, `publications.extra` (jsonb, до 7) — остальные картинки `{image_path,thumb_path,w,h,cap}`. Автор может дописать `cap`/`extra` (политика update own + grant только на эти колонки). В коде — `pics(r)` |
| Миниатюры стилей | Таблица `style_shots` (style → publication_id + номер картинки). Читают все, пишет только админ: шаг «Стиль» → «Миниатюры стилей». Без записи — автоподбор лучшей сцены стиля с упакованными продуктами или алкоголем |
| Админ | Таблица `admins` (сейчас qller96@gmail.com). Меню профиля → «Аналитика и доступ» |

Ключ в `index.html` публичный (publishable): все права ограничены политиками RLS в базе.

## Выкладка на GitHub Pages

Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save. Сайт: https://qller96-blip.github.io/gena/

Библиотека Supabase лежит в `vendor/`, внешние CDN не нужны.

## Выкладка на Vercel (если доступен)

1. vercel.com → Add New → Project → импортировать этот репозиторий.
2. Framework Preset: **Other**. Build Command и Output Directory оставить пустыми.
3. Deploy. Каждый push в `main` выкладывается сам.

## Один раз в Supabase

Authentication → Sign In / Providers → Email → выключить **Confirm email**. Иначе каждому дизайнеру придёт письмо-подтверждение, а бесплатная почта Supabase отправляет всего пару писем в час.

Authentication → URL Configuration → Site URL: адрес сайта на Vercel.

## Пароль команды

Дизайнер регистрируется сам: любая почта, имя и пароль команды. Сменить пароль: войти как админ → меню профиля → «Аналитика и доступ» → «Пароль команды». Уже зарегистрированные входят со старым.

Забыли пароль: Supabase → Authentication → Users → выбрать пользователя → Send password recovery (или удалить и попросить зарегистрироваться заново).

## Что нового (версии)

Список изменений — массив `CHANGELOG` в `index.html`, открывается из футера («Что нового»). Новая версия добавляется первой строкой; у пользователей появляется жёлтая точка, пока они не откроют список. Только изменения, которые видят все: админские функции и эксперименты лаборатории туда не пишем. Нумерация 1.x — тестовая версия; 2.0 — открытие простого режима для всех.
